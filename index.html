OpenAI (유료 · 카드와 크레딧 필요)

  1. platform.openai.com/api-keys에 들어가.
  2. 「Create new secret key」를 누르고, Owned by는 You, 이름은 아무거나, 프로젝트는 Default, 권한은 All로 만들면 돼.
  3. sk-로 시작하는 키는 한 번만 보이니 바로 복사해.
  4. 결제(Billing)에서 월 사용 한도를 낮게 정해 두는 걸 권해.

키는 비밀번호처럼 다루고, 채팅이나 코드에 올리지 마. 이 브라우저에만 저장되고, 「키 지우기」로 지울 수 있어.

API 키는 이 브라우저(localStorage)에만 저장되고, 요청은 해당 제공 업체로 바로 보내. 이 앱 저장소나 서버에는 올라가지 않아. 키 발급: Google AI Studio · OpenAI API keys

현재 프레임을 이 브라우저에서 바로 분석해. API 키가 없어도 돼.

현재 프레임의 여백을 로컬로 추정해. API 키가 없어도 되고, AI 분석 결과와 같이 볼 수 있어.

프레임 차이로 홀드(2코마/3코마)를 세고, AI가 말한 기법·샷 타입을 여기에 모아 줘.

「영상 불러오기」를 누르거나 영상 파일을 화면에 놓으면 됩니다. 같은 폴더에 frames/가 있으면 자동으로 열립니다. 「이미지로 영상」으로 여러 장의 이미지를 이어 붙여 영상으로 만들 수 있고, 이미지마다 유지 프레임(또는 초)과 초당 프레임을 정할 수 있습니다.

슬라이더를 드래그하면 스케치북처럼 빠르게 넘길 수 있어. 「선택만 보기」를 켜면 고른 프레임만 재생·이동돼. 입력창에 포커스가 있으면 단축키는 동작하지 않고 Enter는 적용, Esc는 포커스를 풀어. 연속된 선택은 그 구간의 소리를 이어서 재생하고, 떨어진 프레임으로 넘어갈 때 오디오가 그 시점으로 점프해. 인쇄·콜라주로 고른 프레임을 출력하거나 한 장으로 모을 수 있고, 콜라주 패널의 「영상으로 만들기」로 같은 목록을 웹 브라우저에서 영상으로 저장할 수 있어. 「이미지 저장」으로 현재·선택·범위 프레임을 JPG/PNG(여러 장이면 ZIP)로 받을 수 있고, 구도 가이드를 구워 넣을 수도 있어. 「구도 가이드 (n)」 버튼을 누르면 삼분할·황금분할·황금나선·황금 삼각형·하모닉 아머처·방사형 등 14가지를 체크박스로 고를 수 있고, G 키로 표시를 켜고 끈다. 콜라주·영상·이미지 저장에도 따로 켤 수 있어. 「피사체 박스」는 주요 피사체 상자를 자동으로 잡고(근사, 직접 드래그·크기 조절 가능) 헤드룸·여백 수치를 보여 줘. 「가이드 편집」에서 소실점 드래그, 위·왼쪽 자에서 커스텀 가이드, 두 점 선을 그릴 수 있고, 가이드마다 색·굵기·투명도·실선/점선을 지정할 수 있어(미리 잡은 구도 가이드 색과는 별개, 잠가도 스타일은 유지). 뷰어에서 놓아 둔 커스텀 가이드 가까이 우클릭하면 삭제되고, 「되돌리기」나 Ctrl+Z로 되돌릴 수 있어. 잠긴 가이드는 삭제되지 않아. 커스텀 가이드 목록은 한 줄에 하나씩 나오고, 행을 눌러 스타일을 고치거나 잠그거나 숨기거나 지울 수 있어. 「전체 삭제」와 「선택 삭제」로 여러 개를 한 번에 지울 수 있고(잠긴 건 건너뜀), 「되돌리기」나 Ctrl+Z로 한꺼번에 되돌릴 수 있어. 「두 점 선」은 버튼을 누른 뒤 화면에서 두 점을 차례로 클릭하거나 끌어다 놓으면 되고, Shift는 15도 단위, Esc로 취소하며, 선을 그린 뒤에도 모드는 유지돼. 펜은 「펜 전체 지우기」로 모든 획을 지울 수 있어. 「펜」으로 체크·형광·지우기를 할 수 있어(잠금·출력 옵션, 모든 프레임/이 프레임만). 폴더에서 연 기본 영상에서는 픽셀을 못 읽으니 웹사이트나 「영상 불러오기」를 쓰면 돼. 어니언 스킨은 앞(이전)·뒤(다음) 장수를 슬라이더(최대 30)나 숫자로 남은 프레임까지 따로 지정하고, 가장 먼 장 최소 투명도를 고를 수 있어. AI 분석이 503·429·500으로 바쁠 때는 자동으로 다시 시도하고, 「바쁠 때 자동으로 다른 모델로 전환」을 켜 두면 다음 모델로 넘어가. 취소로 멈출 수 있어. 「분석」의 AI 분석은 고른 제공 업체의 비전 모델로 카메라 각도·샷 타입·애니메이션 기법·색·여백(노즈룸·헤드룸·리드룸)을 설명해 줘. 색채·여백·구도·기법 탭의 로컬 분석은 API 키 없이 웹 버전이나 불러온 영상에서 동작해. API 키는 이 브라우저에만 저장돼.
