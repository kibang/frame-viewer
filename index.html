키 발급 방법

Gemini (무료)

  1. aistudio.google.com/apikey에 들어가 Google 계정으로 로그인해.
  2. 「Create API key」를 누르고, 프로젝트는 기본값 그대로 두면 돼.
  3. AIza로 시작하는 키를 복사해서 위 칸에 붙여 넣어.

OpenAI (유료 · 카드와 크레딧 필요)

  1. platform.openai.com/api-keys에 들어가.
  2. 「Create new secret key」를 누르고, Owned by는 You, 이름은 아무거나, 프로젝트는 Default, 권한은 All로 만들면 돼.
  3. sk-로 시작하는 키는 한 번만 보이니 바로 복사해.
  4. 결제(Billing)에서 월 사용 한도를 낮게 정해 두는 걸 권해.

키는 비밀번호처럼 다루고, 채팅이나 코드에 올리지 마. 이 브라우저에만 저장되고, 「키 지우기」로 지울 수 있어.

API 키는 이 브라우저(localStorage)에만 저장되고, 요청은 해당 제공 업체로 바로 보내. 이 앱 저장소나 서버에는 올라가지 않아. 키 발급: Google AI Studio · OpenAI API keys

슬라이더를 드래그하면 스케치북처럼 빠르게 넘길 수 있어. 「선택만 보기」를 켜면 고른 프레임만 재생·이동돼. 입력창에 포커스가 있으면 단축키는 동작하지 않고 Enter는 적용, Esc는 포커스를 풀어. 연속된 선택은 그 구간의 소리를 이어서 재생하고, 떨어진 프레임으로 넘어갈 때 오디오가 그 시점으로 점프해. 인쇄·콜라주로 고른 프레임을 출력하거나 한 장으로 모을 수 있고, 콜라주 패널의 「영상으로 만들기」로 같은 목록을 웹 브라우저에서 영상으로 저장할 수 있어. 「영상 불러오기」로 로컬 영상도 같은 기능으로 볼 수 있어. 「분석」은 고른 제공 업체의 비전 모델로 카메라 각도·기법·색·(연속이면) 무빙을 설명해 줘. API 키는 이 브라우저에만 저장돼.
