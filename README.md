# 프레임 뷰어

영상을 프레임 단위로 보는 플립북 / 어니언 스킨 / 콜라주 도구입니다. 이 저장소를 GitHub Pages로 공개한 사이트에서 바로 쓸 수 있습니다.

「영상 불러오기」로 로컬 영상(mp4 / webm / mov)도 같은 기능으로 볼 수 있습니다.

## 쓰는 법

- 화살표, 휠, 슬라이더로 프레임 이동, Space로 재생(소리 포함)
- 선택 입력·여기부터/여기까지·썸네일 드래그, 인쇄와 콜라주(프레임 간격은 자유롭게), 같은 목록을 「영상으로 만들기」(웹 브라우저에서 webm/mp4)
- 어니언 스킨: 고스트 / 컬러 / 외곽선 / 차이

로컬에서 쓰려면 이 저장소를 받은 뒤 `index.html`을 브라우저로 여세요. Chrome을 권장합니다.

콜라주 패널의 「영상으로 만들기」는 고른 프레임(선택 순서 또는 범위+간격)을 브라우저에서 영상으로 저장합니다. 재생 fps·프레임 유지·해상도·반복·자막을 고를 수 있고, 프레임이 일정한 간격의 연속이며 재생이 원본 타이밍이면 해당 구간의 원본 소리도 넣을 수 있습니다. 내장 프레임으로 영상을 만들 때는 GitHub Pages 같은 웹으로 열거나 「영상 불러오기」로 연 영상에서 동작합니다. `file://`로 내장 프레임만 열면 브라우저 보안 때문에 픽셀을 읽지 못할 수 있습니다.

「분석」 버튼으로 현재 프레임이나 고른 연속 프레임의 카메라 각도·샷·기법·색(연속이면 카메라 무빙)을 Gemini 또는 OpenAI로 설명할 수 있습니다. API 키는 이 브라우저에만 저장되고, 요청은 해당 제공 업체로 바로 갑니다. 내장 프레임 분석은 GitHub Pages 같은 웹으로 열었을 때(또는 「영상 불러오기」로 연 영상에서) 동작합니다. `file://`로 내장 프레임만 열면 브라우저 보안 때문에 이미지를 읽지 못할 수 있습니다.
