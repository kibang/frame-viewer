# 프레임 뷰어

영상을 프레임 단위로 보는 플립북 / 어니언 스킨 / 콜라주 도구입니다. 이 저장소를 GitHub Pages로 공개한 사이트에서 바로 쓸 수 있습니다.

시작 화면에서 「영상 불러오기」를 누르거나 영상 파일(mp4 / webm / mov)을 넣으면 됩니다. 「이미지로 영상」으로 여러 장의 이미지를 이어 붙여 영상으로 만들 수도 있습니다. 같은 폴더에 `frames/`가 있으면 자동으로 열립니다.


## 이미지로 영상

「이미지로 영상」을 누르거나 이미지 여러 장을 화면에 놓으면, 이미지마다 유지할 프레임 수(또는 초)와 초당 프레임(FPS)을 정해 하나의 영상으로 내보낼 수 있습니다.

- 이미지 추가·폴더 추가, 끌어다 놓기, 썸네일을 끌어 순서 바꾸기, 복제·삭제, 이름순 정렬, 순서 뒤집기
- 한 장마다 프레임 수나 초를 넣고, 「선택에 적용」/「전체에 적용」으로 한꺼번에 맞출 수 있습니다. FPS는 12/24/25/30/60 또는 직접 입력합니다. 아래 줄에 `48프레임 = 2.00초 @24fps`처럼 합계가 바로 나옵니다. 「전체 길이를 N초에 맞추기」는 현재 비율을 유지한 채 프레임을 나눠 전체 길이를 맞춥니다.
- 해상도(첫 이미지 / 1280×720 / 1920×1080 / 직접), 맞춤(안에 맞추기·채워 자르기·늘이기), 배경색, 반복, 왕복(핑퐁), 이미지 사이 크로스페이드, 품질을 고를 수 있습니다.
- 「영상 만들기」는 WebM으로 뽑고, 브라우저가 지원하면 MP4도 고를 수 있습니다. 프레임 수는 타이머가 아니라 지정한 유지 장수 그대로입니다. 「PNG 시퀀스 ZIP」도 받을 수 있습니다. 「뷰어에서 미리보기」로 시퀀스를 프레임 뷰어에서 먼저 넘기며 보고, 영상을 만든 뒤에는 「뷰어에서 열기」로 결과 영상을 프레임 단위로 검사할 수 있습니다.

## 쓰는 법

하단 버튼은 재생·이동, 선택, 내보내기, 어니언 스킨, 구도 가이드, 도구처럼 칸이 나뉘어 있습니다. 「분석」을 누르면 패널이 열리고, 위쪽의 「← 뷰어로 돌아가기」나 「분석 닫기 ✕」, 분석 버튼을 다시 누르거나 Esc로 닫고 화면으로 돌아갑니다. 「이미지로 영상」창은 오른쪽 위 「닫기 ✕」나 Esc로 닫고, 가이드 편집·펜은 「← 보기 모드로」나 Esc로 보기 모드로 돌아갑니다.

- 화살표, 휠, 슬라이더로 프레임 이동, Space로 재생(소리 포함)
- 선택 입력·여기부터/여기까지·썸네일 드래그, 인쇄와 콜라주(프레임 간격은 자유롭게), 같은 목록을 「영상으로 만들기」(웹 브라우저에서 webm/mp4)
- 「이미지 저장」으로 현재 프레임, 선택한 프레임, 또는 범위+간격 프레임을 JPG/PNG로 저장(여러 장이면 ZIP). 구도 가이드를 이미지에 구워 넣을 수 있습니다
- 구도 가이드: 「구도 가이드 (n)」 버튼으로 14가지(삼분할, 황금분할, 황금나선(맞춤/늘이기·4방향·반전), 황금 삼각형, 하모닉 아머처(대각선+수선), 방사형(소실점), 대각선/바로크, 중앙선/십자, 대칭, 다이나믹 시메트리, 4분할, 압축 대각선/삼각 구도, 세이프 에어리어, 커스텀 NxM)를 체크박스로 고릅니다. G 키로 표시를 켜고 끄며, 색·투명도·나선 방향·칸 수는 같은 패널에서 조절합니다. 콜라주·영상·이미지 저장에도 각각 켜고 끌 수 있습니다. 「피사체 박스」는 자동(근사)으로 상자를 잡고 드래그·크기 조절할 수 있으며, 헤드룸·여백 수치가 따라갑니다. 황금나선은 황금 사각형 위에 사분원 호로 그리고 맞춤/늘이기를 고를 수 있습니다. 황금 삼각형과 하모닉 아머처(대각선+수선), 방사형(소실점, 드래그)을 제공합니다. 위·왼쪽 자로 커스텀 가이드를 만들고, 가이드마다 색·굵기·투명도·실선/점선을 지정할 수 있습니다(새 가이드 기본 색은 미리 잡은 구도 가이드 색과 별개). 뷰어에서 가이드 가까이 우클릭하면 삭제되고, 「되돌리기」나 Ctrl+Z로 되돌릴 수 있습니다. 잠긴 가이드는 삭제되지 않습니다. 커스텀 가이드 목록은 한 줄에 하나씩 보이며, 행을 눌러 스타일을 고치거나 잠그거나 숨기거나 지울 수 있습니다. 「전체 삭제」(확인 후)와 「선택 삭제」로 여러 개를 한 번에 지울 수 있고, 잠긴 가이드는 건너뛰며, 「되돌리기」나 Ctrl+Z로 한꺼번에 되돌릴 수 있습니다. 「두 점 선」은 버튼을 누른 뒤 화면에서 두 점을 차례로 클릭하거나 끌어다 놓으면 되고, Shift는 15도 단위, Esc로 취소하며, 선을 그린 뒤에도 모드는 유지됩니다(Esc나 버튼을 다시 누르면 끝). 펜은 「펜 전체 지우기」로 모든 획을 지울 수 있습니다. 펜으로 체크·형광을 그린 뒤 잠그거나 인쇄·콜라주·이미지·영상에 넣을 수 있습니다. 어니언 스킨은 앞(이전)·뒤(다음) 장수를 슬라이더(최대 30)나 숫자 입력으로 남은 프레임까지 따로 지정하고, 가장 먼 장 최소 투명도를 고를 수 있습니다(file://로 폴더의 프레임만 열면 픽셀을 읽지 못해, 웹 버전이나 「영상 불러오기」가 필요합니다)
- 어니언 스킨: 고스트 / 컬러 / 외곽선 / 차이
- 분석 패널 탭: AI 분석 / 색채 / 여백·구도 / 기법. 색채·여백·기법은 API 키 없이 로컬로 계산합니다(팔레트, RMS·WCAG 대비, 색 조화, 헤드룸·네거티브 스페이스, 홀드/2코마 감지). AI 분석은 샷 타입·애니메이션 기법·노즈룸/리드룸 판단 등을 JSON과 함께 보여 줍니다. 제공 업체가 503·429·500으로 바쁠 때는 자동으로 다시 시도하고, 「바쁠 때 자동으로 다른 모델로 전환」(기본 켜짐)이면 다음 모델로 넘어가며, 취소로 멈출 수 있습니다

로컬에서 쓰려면 이 저장소를 받은 뒤 `index.html`을 브라우저로 여세요. Chrome을 권장합니다.

콜라주 패널의 「영상으로 만들기」는 고른 프레임(선택 순서 또는 범위+간격)을 브라우저에서 영상으로 저장합니다. 재생 fps·프레임 유지·해상도·반복·자막·구도 가이드를 고를 수 있고, 프레임이 일정한 간격의 연속이며 재생이 원본 타이밍이면 해당 구간의 원본 소리도 넣을 수 있습니다. 폴더의 프레임으로 영상을 만들거나, 이미지를 캔버스에 구워 내보내거나, 로컬 색/여백 분석을 할 때는 GitHub Pages 같은 웹으로 열거나 「영상 불러오기」로 연 영상에서 동작합니다. `file://`로 프레임만 열면 브라우저 보안 때문에 픽셀을 읽지 못할 수 있습니다. 이때 이미지 저장은 원본 JPG를 장별로 받는 링크로 안내합니다.

「분석」의 AI 탭은 현재 프레임이나 고른 연속 프레임의 카메라 각도·샷 타입·애니메이션 기법·색·여백(헤드룸, 노즈룸, 리드룸)과 (연속이면) 카메라 무빙을 Gemini 또는 OpenAI로 설명할 수 있습니다. API 키는 이 브라우저에만 저장되고, 요청은 해당 제공 업체로 바로 갑니다. 로컬 피사체 상자 추정은 가장자리·색 차이·중앙 가중 휴리스틱이라, 복잡한 컷에서는 오차가 있을 수 있습니다.
