# 프레임 뷰어

영상을 프레임 단위로 보는 플립북 / 어니언 스킨 / 콜라주 도구입니다. 이 저장소를 GitHub Pages로 공개한 사이트에서 바로 쓸 수 있습니다.

「영상 불러오기」로 로컬 영상(mp4 / webm / mov)도 같은 기능으로 볼 수 있습니다.

## 쓰는 법

- 화살표, 휠, 슬라이더로 프레임 이동, Space로 재생(소리 포함)
- 선택 입력·여기부터/여기까지·썸네일 드래그, 인쇄와 콜라주(프레임 간격은 자유롭게), 같은 목록을 「영상으로 만들기」(웹 브라우저에서 webm/mp4)
- 「이미지 저장」으로 현재 프레임, 선택한 프레임, 또는 범위+간격 프레임을 JPG/PNG로 저장(여러 장이면 ZIP). 구도 가이드를 이미지에 구워 넣을 수 있습니다
- 구도 가이드: 「구도 가이드 (n)」 버튼으로 14가지(삼분할, 황금분할, 황금나선(맞춤/늘이기·4방향·반전), 황금 삼각형, 하모닉 아머처(대각선+수선), 방사형(소실점), 대각선/바로크, 중앙선/십자, 대칭, 다이나믹 시메트리, 4분할, 압축 대각선/삼각 구도, 세이프 에어리어, 커스텀 NxM)를 체크박스로 고릅니다. G 키로 표시를 켜고 끄며, 색·투명도·나선 방향·칸 수는 같은 패널에서 조절합니다. 콜라주·영상·이미지 저장에도 각각 켜고 끌 수 있습니다. 「피사체 박스」는 자동(근사)으로 상자를 잡고 드래그·크기 조절할 수 있으며, 헤드룸·여백 수치가 따라갑니다. 황금나선은 황금 사각형 위에 사분원 호로 그리고 맞춤/늘이기를 고를 수 있습니다. 황금 삼각형과 하모닉 아머처(대각선+수선), 방사형(소실점, 드래그)을 제공합니다. 위·왼쪽 자로 커스텀 가이드를 만들고, 가이드마다 색·굵기·투명도·실선/점선을 지정할 수 있습니다(새 가이드 기본 색은 미리 잡은 구도 가이드 색과 별개). 펜으로 체크·형광을 그린 뒤 잠그거나 인쇄·콜라주·이미지·영상에 넣을 수 있습니다. 어니언 스킨은 앞(이전)·뒤(다음) 장수를 슬라이더(최대 30)나 숫자 입력으로 남은 프레임까지 따로 지정하고, 가장 먼 장 최소 투명도를 고를 수 있습니다(폴더에서 연 기본 영상은 픽셀을 읽지 못해, 웹 버전이나 「영상 불러오기」가 필요합니다)
- 어니언 스킨: 고스트 / 컬러 / 외곽선 / 차이
- 분석 패널 탭: AI 분석 / 색채 / 여백·구도 / 기법. 색채·여백·기법은 API 키 없이 로컬로 계산합니다(팔레트, RMS·WCAG 대비, 색 조화, 헤드룸·네거티브 스페이스, 홀드/2코마 감지). AI 분석은 샷 타입·애니메이션 기법·노즈룸/리드룸 판단 등을 JSON과 함께 보여 줍니다. 제공 업체가 503·429·500으로 바쁠 때는 자동으로 다시 시도하고, 「바쁠 때 자동으로 다른 모델로 전환」(기본 켜짐)이면 다음 모델로 넘어가며, 취소로 멈출 수 있습니다

로컬에서 쓰려면 이 저장소를 받은 뒤 `index.html`을 브라우저로 여세요. Chrome을 권장합니다.

콜라주 패널의 「영상으로 만들기」는 고른 프레임(선택 순서 또는 범위+간격)을 브라우저에서 영상으로 저장합니다. 재생 fps·프레임 유지·해상도·반복·자막·구도 가이드를 고를 수 있고, 프레임이 일정한 간격의 연속이며 재생이 원본 타이밍이면 해당 구간의 원본 소리도 넣을 수 있습니다. 내장 프레임으로 영상을 만들거나, 이미지를 캔버스에 구워 내보내거나, 로컬 색/여백 분석을 할 때는 GitHub Pages 같은 웹으로 열거나 「영상 불러오기」로 연 영상에서 동작합니다. `file://`로 내장 프레임만 열면 브라우저 보안 때문에 픽셀을 읽지 못할 수 있습니다. 이때 이미지 저장은 원본 JPG를 장별로 받는 링크로 안내합니다.

「분석」의 AI 탭은 현재 프레임이나 고른 연속 프레임의 카메라 각도·샷 타입·애니메이션 기법·색·여백(헤드룸, 노즈룸, 리드룸)과 (연속이면) 카메라 무빙을 Gemini 또는 OpenAI로 설명할 수 있습니다. API 키는 이 브라우저에만 저장되고, 요청은 해당 제공 업체로 바로 갑니다. 로컬 피사체 상자 추정은 가장자리·색 차이·중앙 가중 휴리스틱이라, 복잡한 컷에서는 오차가 있을 수 있습니다.
